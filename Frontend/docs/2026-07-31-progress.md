# 2026-07-31 Tailscale 실기기 연결

## Android v2.0.1

- `versionCode`: 18
- Tailscale IPv4 대역 `100.64.0.0/10`을 개발 빌드의 Jetson HTTP 주소로 허용한다.
- `100.64.0.0/10` 경계 밖 주소와 공인 HTTP 주소는 계속 거부한다.
- 설정 화면에 Tailscale 주소 예시를 표시한다.
- APK: `Counseling_07_31_v2.0.1_debug.apk`

## 검증

- Android 단위 테스트 전체 통과
- debug APK 빌드 통과
- Galaxy `SM-S936N`에 데이터 유지 방식으로 설치 성공
- 설치 버전: `2.0.1 (18)`
- 저장된 Jetson 주소와 암호화된 앱 인증 토큰 유지 확인
- 휴대폰에서 `http://100.93.236.68:8765/health`: HTTP 200
- 휴대폰에서 `http://192.168.137.238:8765/health`: 연결 실패
  - 휴대폰 Wi-Fi는 `10.112.0.0/19`이고 Jetson 로컬망은 `192.168.137.0/24`이므로 현재 직접 경로가 없다.

## 발견한 설정 문제

- 휴대폰 보호자 서비스 요청은 Jetson에 도착한다.
- `/v1/guardian-alerts` 응답은 HTTP 401이다.
- 앱 설정 파일에는 암호화된 토큰이 있지만 현재 Jetson 인증 토큰과 일치하지 않는다.
- Jetson의 `~/.config/onmom/home_assistant_token`은 아직 없어 IoT 상태가
  `configured=false`다.

## 다음 확인

1. 잠금 해제한 휴대폰 앱에 현재 `~/.config/onmom/jetson_sync_token` 값을 다시 저장한다.
2. 보호자 알림 조회가 HTTP 200으로 바뀌는지 확인한다.
3. Home Assistant 장기 토큰을 Jetson의
   `~/.config/onmom/home_assistant_token`에 권한 600으로 저장한다.
4. 보호자 테스트 알림과 실제 IoT 동작을 검증한다.
