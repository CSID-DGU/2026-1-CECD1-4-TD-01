## Derived-only Jetson sync

앱의 설정 화면에 `Jetson > 파생 정보 전송`을 추가했다.

전송 허용 범주:

- `HEALTH`: Health Connect 일/주 단위 집계 요약
- `PHENOTYPE`: 통화 및 앱 사용 패턴의 집계·변화 요약
- `GALLERY`: 기기 내부 이미지 분석으로 생성한 상담 맥락
- `VOICE_EMOTION`: 최근 음성 감정 분류 결과와 확률(30분 후 만료)

전송에서 제외되는 항목:

- 사진 및 음성 파일/바이트
- 파일 경로와 `content://` URI
- 전화번호 및 개별 통화 원본
- 앱 사용 이벤트와 패키지 원본
- 상담 대화 및 사용자 입력 원문
- 기기 ID

전송은 자동으로 실행되지 않는다. 사용자가 버튼을 눌러야 하며, 요청마다 무작위 `transfer_id`를 만든다.

## Transport safety

- 앱과 Jetson 양쪽에서 고정 `derived-only-v1` 스키마를 검사한다.
- 원본 파일/URI/대화 표식이 발견되면 앱에서 전송을 중단하고 서버에서도 거부한다.
- 요청 크기는 256KB, 개별 요약은 64,000자로 제한한다.
- 리디렉션을 따르지 않는다.
- 평문 HTTP는 Android network security config에서 `iot.local` 한 호스트만 허용한다.
- 다른 호스트와 IP는 HTTPS가 필요하다.
- Bearer 토큰은 앱 디스크에 저장하지 않는다.
- Jetson 서버는 기본적으로 `JETSON_SYNC_TOKEN`이 없으면 시작하지 않는다.

## Health data quality filtering

Health Connect 집계의 `null`을 더 이상 `0`으로 치환해 계산하지 않는다. 다음 값은 일별 합계, 평균, 활동 목표, 상담 프롬프트와 Jetson 전송에서 제외한다.

- 0 또는 미수신 걸음
- 0.02km 이하 이동 거리
- 걸음당 0.20m 미만 또는 2.0m 초과로 걸음 수와 모순되는 거리
- 50kcal 미만 총 소모 칼로리
- 5kcal 미만 활동 칼로리
- 총 소모 칼로리보다 큰 활동 칼로리와 모순되는 총 소모 칼로리
- 35~220bpm 밖의 심박
- 6분 이하 또는 24시간 초과 수면
- 비정상적으로 큰 일일 값과 NaN/Infinity

활동 목표의 달성일, 평균, 진행률 분모에는 유효한 걸음 기록이 있는 날만 들어간다. 무효 날짜와 지표는 화면에 `기록 없음`으로 표시하고 날짜 상세 화면에서 제외 사유를 확인할 수 있다.

유효한 건강 지표가 하나도 없으면 Health RAG 슬롯을 삭제하여 과거의 오래된 요약이 Jetson이나 상담 모델에 다시 전달되지 않게 했다.

## Expanded Health Connect overview

건강 화면에 `Health Connect 수신 현황`을 추가했다. 기존 걸음, 거리, 칼로리, 심박, 수면 합계와 함께 다음 25개 세부 유형을 주/월 단위로 확인한다.

- 운동: 운동 세션, 운동 속도, 운동 파워, 보행/자전거 케이던스, 상승 고도, 오른 층수
- 수면: 세션별 수면 단계(깊은 수면, REM, 얕은 수면, 깨어있음)
- 활력징후: 산소포화도, 혈압, 혈당, VO₂ max, 안정 시 심박수, HRV, 호흡수, 체온, 피부 온도 변화
- 신체/체성분: 체중, 체지방률, 기초대사량, 키, 체수분량, 골량, 제지방량
- 영양/수분: 에너지와 탄수화물/단백질/지방 합계, 수분 섭취

각 항목은 다음 상태를 구분해 표시한다.

- `수신됨`: 유효 범위 검사를 통과한 값과 기간 요약
- `기록 없음`: 레코드가 없거나 0·극소·비정상 값만 있어 계산에서 제외됨
- `권한 필요`: 해당 Health Connect 읽기 권한을 허용하지 않음
- `읽기 실패`: 기기/Health Connect가 해당 유형을 제공하지 않거나 읽지 못함

부분 권한만 허용해도 허용된 기본 지표와 확장 항목은 계속 계산한다. 화면에는 데이터 출처와 워치/휴대전화/체중계 등 기기 종류를 표시하지만, Health RAG와 Jetson에는 출처 패키지, 기기 모델, 측정 시각을 제외한 파생 기간 요약만 넣는다. 운동 GPS 경로와 운동 제목/메모도 읽거나 전송하지 않는다.

확장 요약에도 0·극소·비정상 범위 필터를 적용했다. 운동 시간이 1분 미만인 세션, 비현실적인 활력징후·체성분 값, 0에 가까운 속도·파워·고도·층수·수분 등은 요약에서 제외된다.

## Persistent Jetson authentication

앱과 Jetson을 다시 시작할 때마다 인증 토큰을 재입력할 필요가 없도록 영구 저장을 추가했다.

Android:

- Jetson 주소는 전용 SharedPreferences에 저장한다.
- 토큰은 Android Keystore의 내보낼 수 없는 256-bit AES 키로 AES-GCM 암호화한 뒤 IV와 암호문만 저장한다.
- 복원된 백업처럼 Keystore 키가 달라 복호화가 실패하면 암호문을 삭제하고 다시 입력하도록 한다.
- 토큰은 화면·로그·Jetson 전송 본문에 평문으로 남기지 않는다.

Jetson:

- 수신기는 환경변수가 없으면 `~/.config/onmom/jetson_sync_token`을 읽는다.
- POSIX에서 토큰 파일 권한이 `0600`보다 넓으면 시작을 거부한다.
- `install_user_service.sh`는 안전한 토큰을 생성하고 권한을 설정한 뒤 systemd 사용자 서비스를 등록·실행한다.
- headless 부팅 전 자동 시작은 `sudo loginctl enable-linger "$USER"`로 활성화할 수 있다.

## Debug-only private IP fallback

일부 Android 시스템 DNS가 Chrome과 달리 `iot.local` mDNS 이름을 해석하지 못하는 현상에 대응했다.

- debug APK에서만 사설 LAN IPv4 주소를 평문 HTTP Jetson 주소로 사용할 수 있다.
- 허용 범위는 `10/8`, `172.16/12`, `192.168/16`, `169.254/16`이다.
- 공인 IP와 일반 도메인의 평문 HTTP는 코드 검증에서 계속 거부한다.
- main/release network security config는 계속 `iot.local`만 허용한다.
- debug 소스셋의 network security config만 cleartext를 열고, 실제 연결 전 debuggable 플래그와 사설 IP 범위를 다시 검사한다.
- 리디렉션은 계속 비활성화한다.
- 설정 화면에 `.local` 실패 시 사설 IP 입력 방법을 표시한다.
